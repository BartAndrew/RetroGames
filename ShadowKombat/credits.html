Shadow Kombat — Asset Credits

V1.1 uses original code-rendered character illustrations, costumes, environmental art and particles, with the following third-party audio distributed under CC0 1.0 (public-domain dedication).

  • Heavy Battle 2 — heavy metal battle music downloaded from OpenGameArt; file heavy_battle_2_bpm185_0.ogg. CC0. Used as looping combat music.
  • Whoosh sound — downloaded from OpenGameArt, file whoosh2_0.wav. CC0. Used during attacks.

The audio files are downloaded and included in the Vercel static build. If recorded audio cannot be played, the game retains synthesized audio fallbacks. Sound effects synthesized by the game's Web Audio code are original.

No official Mortal Kombat music, characters, trademarks or artwork are bundled; this is an independently developed fighting game.
