01 / WHAT TO TEST

Playtest checklist

  1. Check startup, loading, and the main menu.
  2. Choose fighters and an arena; check previews and animations.
  3. Try movement, jumps, block, punch, kick and special attacks.
  4. Play a full round; check hits, health, meter, timer and knockouts.
  5. Try pause, resume, rematch, CPU, local multiplayer and training where available.
  6. Record visual glitches, crashes, slowdowns and controller issues.

02 / HELP IMPROVE THE GAME

Report what you find

When reporting a problem, include the exact build you tested, your device and input method, the fighters and stage, plus steps to reproduce. Screenshots or a short recording help.

Report a bug or send feedback ↗

Feedback opens a pre-filled GitHub issue. You will need a GitHub account to submit it. Do not report the V6.8 browser baseline as Build 12.

Controls for the existing V6.8 browser build: P1 uses WASD, E to block, F/G to attack and H for special; P2 uses arrows, I to block, J/K to attack and L for special. P or Escape pauses. Build 12 controls will be confirmed with its release.
