# Stereotype Fighters V6.1 runtime assets

V6.1 keeps the 20-fighter roster introduced in V6 and hardens the runtime asset pipeline.

## Character changes

The V6 roster patch in `tools/roster-v6.json` replaces the legacy Lefty Liberal and Agenda Fluid definitions and adds Gym Bro and Bogan Tradie. Their runtime atlases live in `assets/characters/v6/`.

## Arenas

The six selectable arena images live in `assets/backgrounds/game/`. V6.1 resolves arena URLs relative to the ES module with `import.meta.url`, so the same paths work for the stage picker and combat renderer on GitHub Pages and nested deployments.

If an arena image cannot be decoded, the canvas renders the procedural Neon Quarter fallback instead of a blank/black arena.
