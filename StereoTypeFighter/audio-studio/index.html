Audio cues and planned additions

Current: round music sketches, UI clicks, hits, attacks, defenses, synthesized voice-like grunts. Next: stage-specific loops, crowd ambience, announcer voices and 3D spatial audio. Original generated demos are not substitutes for the downloaded third-party sound packs.

Project data & integration

Export a manifest for Unreal Engine and the web version of Stereotype Fighters. Ratings, files, source packs, character overrides and global defaults are included as metadata. Audio binaries are not embedded in the JSON; keep the original files when transferring to another computer.

Audio architecture

Engine event → character override → global default → silence. Each move has a stable event ID and may point to one selected sound. Later versions can add weighted random variants, pitch randomisation, layered sounds, spatial routing and mix presets.

Upcoming roadmap

v1: local import, playback, rating, metadata, fighter assignments, export. Next: waveforms, waveform trimming, volume/pitch preview, layered impacts, subcategories, random sound pools, batch tagging, licence provenance, shared cloud library and Unreal/JS runtime adapters.
