# Stereotype Fighters V6.4 — instant fighter portraits

V6.4 fixes the V6.3 fighter-select regression where most roster cards showed initials/placeholders instead of the actual fighters.

## Fighter select

- Adds one lightweight 320×256 WebP portrait atlas containing all 20 fighters, stored as four small cacheable base64 payload chunks for reliable GitHub transport and decoded once in the browser.
- Every fighter card now shows real character artwork as soon as the portrait atlas arrives; full combat sheets are no longer required to paint the roster.
- The two large player previews also show the selected fighter portrait while the full move set is being prepared.
- If a full legacy move set fails to process, the portrait remains visible and the user can retry or choose another fighter.

## Loading performance

- Only the two selected fighters are required before the Fight button becomes available.
- The default Lefty Liberal / Bogan Tradie compact atlases are preloaded.
- Agenda Fluid and Gym Bro warm during browser idle time rather than blocking initial interaction.
- Legacy 1536×1024 sheets stay on-demand and are primed on hover/focus/pointer-down.
- Arena thumbnails remain lazy loaded.
- The portrait atlas uses four tiny parallel payload requests instead of downloading and processing 20 full fighter sheets on startup.

## QA

`tools/verify-v6-assets.mjs` now validates the portrait atlas in addition to V6 fighter atlases and arena WebPs.

```bash
node StereoTypeFighter/tools/verify-v6-assets.mjs
```
