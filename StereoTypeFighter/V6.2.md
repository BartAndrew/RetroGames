# Stereotype Fighters V6.2 — runtime integrity pass

V6.2 hardens the 20-fighter roster and six selectable arenas.

- Lefty Liberal and Agenda Fluid use their V6 replacement atlas definitions.
- Gym Bro and Bogan Tradie remain selectable V6 additions.
- The four V6 atlas definitions use a 512×240 / 64×40 grid with 8 columns.
- Stage thumbnails and the fight renderer resolve arena URLs from the same ES-module base.
- Stage images only replace the procedural fallback after a successful browser decode.
- Sprite loading validates atlas dimensions and capacity before a fighter is marked ready.
- The procedural Neon Quarter remains the visual fallback if a selected stage fails to decode.
- The fighter-select previews continue cycling through the mapped move set so animations can be visually checked before a match.

For future runtime-asset updates, run:

```bash
node StereoTypeFighter/tools/verify-v6-assets.mjs
```

The repository workflow `.github/workflows/stereotype-fighter-assets.yml` runs the same check for Stereotype Fighter changes.
