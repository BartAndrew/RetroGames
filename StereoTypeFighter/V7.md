# StereoType Fighter V7 (vertical slice)

Open `v7.html` (serve over HTTP: `python3 -m http.server 8080`, then `/StereoTypeFighter/v7.html`).
`index.html` now opens V7. The previous 20-fighter V6.8 game is kept at `index-v68.html`. (`v7.html` is the same page.)

- Fighters: Bogan Tradie, Yuppie, Gym Bro. Modes: Story, Versus CPU, Local 2P, Training.
- Controls (P1 / P2): move A D / arrows, jump W / Up, crouch S / Down, block E / I, punch F / J, kick G / K, special H / L.
- Combos: jab > jab > cross (forward+punch) > uppercut (down+punch) > special. Light chains, hit-stop, juggles, counter hits.
  Sweep = down+kick, overhead = forward+kick, dash = double-tap, super = down+special at full meter.
- Story: `story-v7.js` (prologue, pre-fight, post-fight, ending per fighter). Cutscene art slots: `art/scenes/`.
- Art: realistic frames plug in via `art/manifest.json`; see `art/ART_SPEC.md`. Until then a stand-in figure is drawn.
- Tests: `node tests/combat-v7.unit.mjs`

## Full roster (20 fighters)
- All 20 fighters are playable. The three hand-tuned originals live in `roster-v7.js`; the other 17 come from `tools/cast_data.py` via the generated `cast-v7.js`.
- **Edit `tools/cast_data.py`, then run `python3 tools/build-v7-prompts.py`.** That regenerates `cast-v7.js`, `art/PROMPTS.md`, `art/prompts-v7.json` and `art/manifest.v7.template.json` together.
- Story mode is a 4-fight ladder per fighter (their `rivals` list), with a prologue and an ending each. Pre- and post-fight scenes for any pairing are built from each fighter's own voice lines (`taunt/answer/quip/ready`, `win/lose/respect`), so 20 fighters need 20 voices rather than 380 scripts. The original three keep their hand-written scenes against each other.
- Cutscene art: prologue, ending, and one face-off per new fighter (66 scene prompts in total). Anything without art uses staged portraits.
- Tests: `node tests/combat-v7.unit.mjs` and `node tests/roster-v7.unit.mjs`.
