# StereoType Fighter V7 (vertical slice)

Open `v7.html` (serve over HTTP: `python3 -m http.server 8080`, then `/StereoTypeFighter/v7.html`).
`index.html` now opens V7. The previous 20-fighter V6.8 game is kept at `index-v68.html`. (`v7.html` is the same page.)

- Fighters: Bogan Tradie, Yuppie, Gym Bro. Modes: Story, Versus CPU, Local 2P, Training.
- Controls (P1 / P2): move A D / arrows, jump W / Up, crouch S / Down, block E / I, punch F / J, kick G / K, special H / L.
- Combos: jab > jab > cross (forward+punch) > uppercut (down+punch) > special. Light chains, hit-stop, juggles, counter hits.
  Sweep = down+kick, overhead = forward+kick, dash = double-tap, super = down+special at full meter.
- Story: `story-v7.js` (prologue, pre-fight, post-fight, ending per fighter). Cutscene art slots: `art/scenes/`.
- Art: realistic frames plug in via `art/manifest.json`; see `art/ART_SPEC.md`. Until then a stand-in figure is drawn.
- Tests: `node tests/combat-v7.unit.mjs`
