# Stereotype Fighters V6.3 — fast select + animation stability

V6.3 focuses on two problems visible in V6.2: the fighter-select screen doing too much work up front, and the new atlas fighters shifting slightly between frames because trimming recentred each sprite.

## Faster select screen

- The default match now uses Lefty Liberal vs Bogan Tradie so the first two animated previews come from the compact V6 atlases.
- All four V6 atlas fighters load immediately because their runtime files are small.
- Legacy full-resolution fighter sheets no longer all load and process during startup.
- Legacy fighters show an instant lightweight placeholder card and load their full move set only when selected or opened in Animation Lab.
- Hover/focus/pointer-down primes a fighter source in the browser cache before selection.
- Random selection can choose any fighter and automatically loads that fighter on demand.
- The Start button waits only for the two selected fighters, not the entire roster.
- Arena thumbnails use lazy image loading.
- The page preloads the four compact V6 atlases and module-preloads the V6 runtime files.

## Animation stability

V6 atlas frames now retain the original cell-relative foot/centre anchor when transparent padding is trimmed. This prevents each frame being re-centred independently and reduces horizontal wobble/foot sliding in Lefty Liberal, Agenda Fluid, Gym Bro and Bogan Tradie.

## Compatibility

The existing V5 source-sheet extractor remains unchanged for legacy fighters. Once a legacy fighter is loaded it stays cached in memory for instant reselection during that session.

Asset QA remains available with:

```bash
node StereoTypeFighter/tools/verify-v6-assets.mjs
```
