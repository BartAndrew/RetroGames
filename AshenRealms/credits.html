Credits & asset licences

Ashen Realms is an original browser beat-'em-up inspired by classic side-scrolling fantasy arcade games. No Golden Axe or Sega-owned sprites, characters, soundtrack or trademarks are included.

Visuals & code

Character animation sheets are supplied by LuizMelo, released under Creative Commons Zero 1.0 (CC0). They have been resized and adapted to Ashen Realms' combat and rendering system. The original Canvas scenery, effects, and SVG cover artwork were created for RetroGames.

  • Medieval King Pack 2 — playable Iron Warden, idle / run / attacks / hit / death.
  • Medieval King Pack — Cinder Warden boss, idle / run / attacks / hit / death.
  • Monsters Creatures Fantasy — goblin, skeleton and mushroom enemies with animated movement, attacks, hit reactions and death.
  • CC0 1.0 licence

Assets were obtained from publicly available GitHub copies of the corresponding original LuizMelo CC0 sprite packs and embedded locally in assets-hero.js, assets-boss.js and assets-monsters.js. Original repositories: hero, boss, enemies.

Original cinematic environments

Three original fantasy environment images were generated for Ashen Realms and optimised into AVIF for self-hosted delivery: The Burning March (fire-scarred fortress), The Forgotten Woods (moonlit ancient forest), and The Cinder Throne (volcanic citadel). Each stage includes procedural fog, particles, atmospheric lighting, and additional parallax floor detail. The full-resolution source artwork is retained separately from the optimised web build.

V1.4 layered parallax artwork

Three additional original cinematic artworks were generated specifically for depth and parallax. They were adapted into three transparent image layers per stage (middle-distance scenery, travelling foreground-ground detail, and cropped foreground silhouettes). The environment renderer scrolls distant scenery slowly, midground scenery at an intermediate speed and masked foreground details faster than the fighters, with subtle fog and floating particles. Each image is self-hosted as an optimised WebP embedded in the game. The original generated source images are preserved separately.

Sounds

Combat effects are loaded on demand from a public GitHub mirror of Kenney's Impact Sounds and RPG Audio libraries, distributed under CC0. Sound playback requires internet connectivity. If a remote sound is unavailable, the game continues using synthesised Web Audio cues.

  • Kenney · Impact Sounds
  • Kenney · RPG Audio
  • Audio mirror used by the game

The musical score is original procedural synthesised browser audio, not extracted from an existing game soundtrack.
